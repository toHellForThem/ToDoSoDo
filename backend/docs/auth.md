# Аутентификация и безопасность

## Логин

- Логин **регистронезависимый**: `Alice`, `alice` и `ALICE` — один аккаунт.
- При регистрации логин нормализуется: `strip()` + `lower()`.
- Допустимые символы: `a-z`, `0-9`, `_`, `.`, `-`; длина 3–32.
- Поиск пользователя идёт по `LOWER(username)`, поэтому старые записи
  с другим регистром продолжают находиться.

## Пароль

- При регистрации: 6–128 символов.
- При входе политика не применяется, чтобы не ломать старые аккаунты
  с короткими паролями; проверяется только непустое значение.
- Пароли и токены не логируются.

## Rate limit

- In-memory, по нормализованному логину.
- По умолчанию 5 попыток за 60 секунд (`AUTH_RATE_LIMIT_ATTEMPTS`,
  `AUTH_RATE_LIMIT_WINDOW_SECONDS`).
- Счётчик сбрасывается после успешного входа/регистрации.
- Ограничение действует на `client:login` и `client:register`.

## JWT и сессия

- Алгоритм HS512, срок жизни 7 дней (`JWT_EXPIRE_DAYS`).
- `JWT_SECRET_KEY` обязателен и не имеет дефолта в коде.
- Refresh token пока не вводим: истёкший токен → `server:auth_expired`,
  клиент очищает сессию и просит войти заново.
- Logout клиентский: сервер выходит из комнаты и очищает socket-сессию.
  Отзывного списка токенов нет — для текущей модели угроз это осознанное
  решение; при необходимости добавим `token_version`/blacklist.

## CORS

- `SIO_CORS_ORIGINS` — список origin'ов через запятую или `*`.
- По умолчанию разрешены Expo web и Tauri:
  `http://localhost:8081`, `http://127.0.0.1:8081`,
  `tauri://localhost`, `http://tauri.localhost`.
- `*` оставлен как явный opt-out для локальной отладки, но не является
  дефолтом.
